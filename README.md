# Microsoft Sentinel SOC Labs

Hands-on Security Operations Center projects focused on Microsoft Sentinel, KQL, detection engineering, threat hunting, and incident investigation.

## About This Portfolio

This repository documents practical SOC investigations and detection engineering exercises performed using Microsoft Azure and Microsoft Sentinel.

The goal is to demonstrate real-world SOC analyst skills including:

- Security event analysis
- KQL query development
- Detection engineering
- Microsoft Sentinel analytics rules
- Alert and incident investigation
- Threat hunting
- MITRE ATT&CK mapping
- Incident response recommendations
